# Computer Lucky Number Game

## About the Project
The Computer Lucky Number Game is a simple and interactive game where the player tries to guess a lucky number selected by the computer. The game provides feedback to help the player determine whether their guess is correct. It is designed to make learning programming fun while improving logical thinking and problem-solving skills.

## Features
- Computer selects a lucky number.
- Player enters a number to guess.
- Displays feedback based on the player's guess.
- Simple and interactive gameplay.
- Beginner-friendly project.

## Technologies Used
- HTML
- CSS
- JavaScript
